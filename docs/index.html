Issue-time travel time forecasting without future leakage

Probabilistic arterial travel-time forecasts built strictly from completions observed by the issue time match thirty-minute look-ahead accuracy.

Three empirical findings from Hangzhou

Evaluated across 113,006 matched trajectories on a signalized urban arterial using gap-respecting moving-period-block bootstrap inference and Holm-Bonferroni multiplicity adjustments.

Frozen evaluation protocol and guardrails

Every architecture, mixture count, block length, and publication policy is fixed exclusively on training and validation periods before touching the held-out test set once.
